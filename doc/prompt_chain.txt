- Đánh dấu: @RestController, @RequestMapping(path = "/api/category")

1. GET /api/category
   - Lấy danh sách toàn bộ Category.
   - Trả về: ResponseEntity<Response>(new Response(true, "Thành công", list), HttpStatus.OK).

2. POST /api/category/getCategory?id=...
   - Nhận `@RequestParam("id") Long id`.
   - Nếu tìm thấy: trả về status 200 kèm Response(true, "Thành công", category).

   - Nhận `@RequestParam("categoryName") String categoryName` và `@RequestParam(value = "icon", required = false) MultipartFile icon`.

   - Nếu chưa tồn tại: kiểm tra icon có rỗng không; nếu có icon thì sinh UUID, lấy tên file qua `storageService.getSorageFilename(icon, uuString)`, lưu file qua `storageService.store(...)`, gán vào category.setIcon(...).

4. PUT /api/category/updateCategory
   - Nhận `@RequestParam("categoryId") Long categoryId`, `@RequestParam("categoryName") String categoryName`, `@RequestParam(value = "icon", required = false) MultipartFile icon`.
   - Nếu không tìm thấy Category -> trả về BAD_REQUEST cùng Response(false, "Không tìm thấy Category", null).
   - Nếu tìm thấy: nếu có file icon mới thì lưu file mới và cập nhật icon; cập nhật categoryName; gọi service.save(); trả về 200 OK cùng Response(true, "Cập nhật Thành công", category).

5. DELETE /api/category/deleteCategory?categoryId=...
   - Nhận `@RequestParam("categoryId") Long categoryId`.
   - Nếu không tìm thấy -> trả về BAD_REQUEST cùng Response(false, "Không tìm thấy Category", null).
   - Nếu tìm thấy -> gọi `categoryService.delete(...)` và trả về 200 OK cùng Response(true, "Xóa Thành công", optCategory.get()).
